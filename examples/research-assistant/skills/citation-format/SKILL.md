# Citation format

Every finding is one line, in this shape:

```
[n] <claim, one sentence> — <source title>, <publisher>, <date> — <url>
```

Rules that matter:

- **One claim per entry.** If a sentence has two facts that came from
  different places, it is two entries.
- **Number entries once and never renumber.** Later text refers to `[3]`; if
  `[3]` moves, every reference silently breaks.
- **Date is the source's date, not today's.** An undated source is recorded
  as `n.d.` — do not substitute the retrieval date, which implies a currency
  the source does not have.
- **Quote when the wording is the point.** Paraphrase otherwise, and never
  paraphrase a number.

When two sources disagree, record both entries and add a third line marking
the disagreement:

```
[!] [4] and [7] disagree on <what>. [4] says <x>; [7] says <y>.
```

A claim you inferred rather than read gets no number. Mark it inline as
`(inference)` so a reader can tell the difference at a glance.
